# Zoom Support Navigator

React/Vite and Supabase foundation for the approved Zoom Support Navigator project.

## Safety boundary

- Dedicated Supabase project only: `eefpsujuvwfkpuiejtft` (Wagmi Support).
- Never use a Medify Support Navigator project, URL, key, table, or function.
- Browser configuration accepts only `VITE_SUPABASE_URL` and `VITE_SUPABASE_PUBLISHABLE_KEY`.
- Service-role/secret keys belong only in Supabase Edge Function secrets and are never committed.

## Local setup

1. Copy `.env.example` to `.env` and insert the **publishable** key.
2. Run `npm install`.
3. Run `npm run dev`.

Quality commands:

```text
npm test
npm run lint
npm run build
git diff --check
```

## Supabase source

Migrations and Edge Functions live in `supabase/`. The current machine needs Supabase project access before `supabase link --project-ref eefpsujuvwfkpuiejtft`, migration pushes, function deployment, and Advisor checks can run.

## Required source assets

The approved plans require the original Navigator process content and `avatar_assets_final.zip` (187 approved image files). Neither is available in this workspace. The live reference requires a signed-in ChatGPT session from this environment, so its content cannot be extracted anonymously. These assets must be supplied before the final Navigator shell and avatar gallery can be completed without inventing support procedures or substitute avatars.
